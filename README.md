# 体育场馆预约页面

这是根据提供的界面制作的静态演示网站。首页显示当天及随后两天的可预约日期；点击日期切换时段，点击“可预约”后，记录会显示在“我的预约”。可以取消预约，过去和取消的记录会进入“历史预约”。日期卡片下方只显示当天的剩余名额数字，包括负数。

点击页面右上角的 `⋮` 可以手动调整三个日期各自的剩余名额，也能单独将某个时段设为“已约”。剩余名额为 0 或负数时，该日尚未开始的时段全部显示“已约”；预约成功后名额减 1，取消预约后名额加 1。

## 运行

在本目录执行：

```powershell
python -m http.server 8000
```

然后在浏览器打开 `http://localhost:8000/`。没有第三方依赖。

## 数据说明

预约记录和手动设置存储在当前浏览器的 `localStorage` 中。日期使用访问者设备的本地日期和时间，在午夜、窗口重新获得焦点或重新打开页面时更新。首次打开时，为复现截图，三天的名额初始为 `-1`、`-1`、`107`；第三天的 16:00–18:00 和 20:00–22:00 初始设为“已约”。之后进入预约窗口的新日期初始名额为 `107`，这只是演示值，不代表学校系统的实时名额。“候补排队”和“登出”保留了原图样式，但此版本没有候补、登录、服务端名额管理或跨设备同步，不能作为学校正式预约系统直接投入使用。
